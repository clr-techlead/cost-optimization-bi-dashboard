# Cost Optimization & Business Intelligence Dashboard

A Power BI portfolio project designed to help decision-makers understand spending, detect budget deviations, and prioritize cost-reduction opportunities.

## Business objective

Turn raw expense data into actionable financial insights by answering:

- Where is the organization spending the most?
- Which departments and categories exceed budget?
- What recurring costs create the greatest savings potential?
- Which suppliers or expense types require management attention?

## Key metrics

- Total Spend
- Budget Variance
- Savings Opportunity
- Savings Rate
- Average Cost per Transaction
- Top Cost Drivers
- Department Efficiency Score

## Planned solution

- Power BI executive dashboard
- Power Query data transformation
- Star-schema semantic model
- DAX measures for financial and operational KPIs
- Synthetic dataset with realistic business scenarios
- Documented assumptions and business definitions

## Dashboard sections

1. Executive overview
2. Budget versus actual analysis
3. Cost-driver decomposition
4. Department and supplier performance
5. Savings opportunity prioritization
6. Monthly trend and variance analysis

## Technology stack

- Power BI
- DAX
- Power Query (M)
- SQL Server
- Python for data generation and validation
- GitHub for version control and documentation
